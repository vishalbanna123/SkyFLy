# FlySmart Backend

This folder contains the Node.js / Express backend for the FlySmart project.

## Available scripts

- `npm install` - install dependencies
- `npm run dev` - start the server with `nodemon`
- `npm start` - start the server with Node

## API endpoints

- `GET /api/health`
- `GET /api/destinations`
- `GET /api/flights?from=JAI&to=BOM&date=2026-05-15`
- `GET /api/bookings`
- `POST /api/bookings`
- `POST /api/auth/login`
- `POST /api/auth/signup`
- `GET /api/profile`
